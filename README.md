## Project Overview

This project focuses on building an interactive **Power BI dashboard** to analyze sales performance, profitability, regional trends, and business insights using the **Global Superstore dataset**.

The dashboard helps stakeholders make data-driven decisions through KPI tracking, trend analysis, and interactive filtering.

## Features

* KPI Metrics (Sales, Profit, Orders, Profit Ratio)
* Sales Trend Analysis (2011–2014)
* Regional Sales Performance
* Profit by Sub-category Analysis
* Category-wise Sales Comparison
* Interactive Filters & Slicers

## Tools Used

* Power BI
* Microsoft Excel
* Data Visualization

## Key Insights

* Sales increased steadily from 2011 to 2014
* Technology generated highest sales
* Central region contributed highest revenue
* Copiers generated highest profit
* Certain categories such as Tables showed lower profitability
